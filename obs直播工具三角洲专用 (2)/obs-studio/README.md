## 快速开始

1. 下载 `obs直播工具三角洲专用.zip` 并解压
2. 打开 OBS Studio，加载内置配置
3. 添加游戏源（Game Capture / 窗口捕获）
4. 开始直播

> 视频教程用系统自带播放器打开，如无法播放请安装 [VLC](https://www.videolan.org/) 或 [PotPlayer](https://potplayer.daum.net/)。
